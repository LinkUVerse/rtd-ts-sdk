# dapp-kit-react

React hooks and components for building decentralized applications on the [Rtd](https://rtd.io)
blockchain. Built on top of [`rtd-dapp-kit-core`](https://www.npmjs.com/package/rtd-dapp-kit-core).

Provides a `DAppKitProvider`, ready-to-use `ConnectButton` and `ConnectModal` components, and hooks
like `useDAppKit`, `useCurrentAccount`, `useCurrentWallet`, and more.

## Installation

```sh
npm i rtd-dapp-kit-react rtd-typescript
```

## Documentation

See the [dApp Kit docs](https://sdk.linkuverse.com/rtd/dapp-kit) for full usage instructions,
guides, and API reference.
